# Text Document Analyzer

## Overview
A beginner Python project that analyzes text and provides basic statistics about a document.

## Features
- **Word Count:** Counts the total number of words in a text.
- **Unique Words:** Identifies the number of unique words.
- **Most Frequent Words:** Finds the word or words that appear most frequently.

## Technologies Used
- Python
- Dictionaries
- Lists
- Loops and conditional statements
- Object-oriented programming (OOP)

## What I Learned
Through this project, I practiced:
- Creating classes and objects.
- Defining methods and using `self`.
- Processing text using `split()`.
- Counting word frequencies using dictionaries and `.get()`.
- Identifying unique words using lists.
- Finding the maximum frequency using `max()`.

## How It Works
The project uses a Python class to store a text and analyze it through separate methods.
